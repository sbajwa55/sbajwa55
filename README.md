# AWS for Database Administrators — Lab Files

Companion code for the book *AWS for Database Administrators* by Sandeep S. Bajwa
([Bajwa Consulting Services](https://bajwaconsulting.com)).

> ⚠️ These labs are for practice only. Do not run them against production systems.

## Labs
| Lab | Folder | Topic |
|-----|--------|-------|
| 1 | `lab1-oracle-to-oracle-ec2` | Oracle to Oracle on EC2 |
| 2 | `lab2-oracle-to-mysql` | Oracle to MySQL on AWS |
| 3 | `lab3-mysql-to-oracle-postgres` | MySQL to Oracle and Postgres |
| 4 | `lab4-postgres-to-oracle` | Postgres to Oracle |
| 5 | `lab5-goldengate-to-aws` | GoldenGate to AWS |

Each lab is independent. Host names (`*.bcs.com`) and `192.168.55.x` addresses are examples. Replace them with your own.
